## What Was Built

### 1. Safety Policy (`config/safety-policy.yaml`)
- Per-run limits: 200 files / 5GB
- Large file protection: 100MB threshold
- Protected paths: .git, node_modules, .venv, dist, build, memory/*.md, secrets
- Whitelist: core workspace files (FILE-MAP.md, README.md, SOUL.md, etc.)
- Confirm-required patterns: scratch/, out/, logs/, archives, databases

### 2. Cleanup Rules (`hooks/cleanup_rules.yaml`)
9 rules defined:
- `tmp-files`: *.tmp, *.swp, *.bak → delete after 7d
- `os-artifacts`: .DS_Store, Thumbs.db → delete after 7d
- `python-cache`: __pycache__, *.pyc → delete after 7d
- `node-cache`: .cache/ → delete after 7d
- `old-logs`: *.log >30d or >10MB → archive
- `scratch-files`: scratch/** >7d → move to memory/scratch-archive
- `experiment-artifacts`: out/, experiments/ >60d → archive
- `research-build`: build/dist/.cache in research/ → delete after 14d
- `core-files-keep`: README.md, FILE-MAP.md, SOUL.md, etc. → keep forever
- `daily-memory-keep`: memory/*.md → keep forever

### 3. Governance Script (`scripts/govern.sh`)
Features:
- Dry-run default (`--apply` to execute)
- Scans target directory (default: workspace root)
- Classifies files: keep / review / trash
- Detects junk patterns, old logs, large files, duplicates (md5)
- Generates report: `memory/YYYY-MM-DD-govern-report.md`
- Moves trash to `memory/trash/YYYY-MM-DD/`
- Logs all actions: `memory/YYYY-MM-DD-cleanup-log.md`
- Interactive confirmation before apply
- Enforces limits (max files/bytes)
