## KEV 研究线：从蔡登「部署后自进化」到 P2 证伪实验 <!-- project: github.com/Xplore-LAB/home-lab434 -->

- **来源**：DeepTech × 蔡登访谈（`mp.weixin.qq.com/s/DuJbfu8WMlDBw3ufHViBFw`）——第四条规模化轴 = Post-Deployment Scaling；ICL 是「终局学习方式」；真实工作没有 RL 那种明确对错，**弱反馈**才是钥匙。
- **研究笔记** `~/Documents/notes/KEV-post-deployment-scaling.md`：P1 弱反馈信号建模 / P2 判断式 ICL / P3 短上下文内化 / P4 通用能力保留 / P5 可解释性张力；含 4.3 节「为什么这条路天然适合学界/中小团队」（引蔡登原话：前三条轴拼资源，只有大厂玩得起）。
- **产品映射**：KEV = 概率化是非判断系统（kev-gui.vip.cpolar.cn），输出「结论 + 概率」。与 P2 天然对齐——**soft label 就是不需要外部标注的 ICL 训练信号**。
- **P2 pilot 已跑**（`~/research/kev-p2-icl/`）：
  - 合成数据 100 条，5 类业务判断（库存/折扣/风控/工单/报销），分 **A 类（rule 写在 prompt 里）** 与 **B 类（rule 隐式，须靠例子推断）**
  - K=0/4/16 × 分层抽样 5A+5B，模型 `MiniMax-M3.1-Flash-Preview`（`https://api.minimaxi.com/v1/chat/completions`，key 在 `~/.openclaw/.env` 的 `MINIMAX_API_KEY`）
  - **结果**：A 类全程 1.000；**B 类 K=0 0.600 → K=4 1.000 → K=16 1.000**；B 类置信度同步从 80-99% 升到 99-100%
  - **结论**：P2 成立——分类器 + 置信度分布的输出**能做 ICL**，且 K=4 够用
  - **警告**：n=5 per cell 太小，且 K=4 已封顶（ceiling effect），**必须放大样本 + 加难度**（多条件/隐晦 rule）才能下硬结论
- **踩坑**：`vllm :8000` 上 `test_vllm.py` 里的 `pse434` key 已失效（两个端点都 401）；改用 `~/.openclaw/.env` 的 minimax 凭据。MiniMax 模型名是 `MiniMax-M3`（**不带** `minimax/` 前缀，带了报 unknown model）。M3 走 chain-of-thought，response 被 `<think>` 吃掉，需 `max_tokens=500` 且在 parser 里剥掉思考段。
- **待办**：n=50 per K + 加 K=64/256 看长上下文塌方 + 加难度 + 切 KEV 真实日志。
