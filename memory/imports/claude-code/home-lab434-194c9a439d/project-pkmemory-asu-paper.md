## 论文题目
- 中文：**面向空分运行监盘的工业智能体过程知识记忆构建方法**
- 英文：**A Process Knowledge Memory Construction Method for Industrial Agents in Air Separation Operation Monitoring**

## 主线逻辑
> 多源工业知识难以直接被智能体利用 → 构建统一的过程知识记忆 → 生成过程知识链 → 分别支撑模型内化与在线推理 → 通过一致性校验和运行反馈更新记忆。

## 三个核心贡献（必须可验证）
1. **统一记忆表示**：5 类过程知识记忆（状态/规程/案例/安全边界/机理）+ 统一记忆单元
2. **过程知识链构建**：基于启发式场景的结构化问答构建
3. **一致性筛选与调用**：多维一致性筛选 + 双支路使用（模型内化 + 在线推理）

## 关键定义（已锁定）
- **统一记忆单元**：M_i = ⟨C, P, E, D, R, O, V, B, S⟩（场景上下文、异常现象、变量证据、诊断结果、原因解释、处置操作、验证指标、风险边界、知识来源）
- **过程知识链**：C → P → E → D → R → O → V → B
- **输入**：X_t = {S_t, A_t, T_t, C_t}（状态、报警、趋势、上下文）
- **输出**：Y_t = {D, E, R, O, V, B}（诊断决策对象）
