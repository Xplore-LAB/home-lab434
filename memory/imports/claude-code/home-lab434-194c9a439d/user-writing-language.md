用户的论文写作目标语言是 **中英文并行**：同一篇论文同时准备中文版（如投 CAC2026 自动化学报）和英文版（如投 IEEE/SCI 会议期刊）。

**Why:** 用户已有 CAC2026 项目的中文初稿 + 0526-en 英文翻译版，这是中英双轨的实际证据。

**How to apply:**
- 写综述/段落时默认同时给出中文和英文两版（除非用户只问一种）
- 涉及专有名词时首次出现给中英对照，例如「操作知识链（Operation Knowledge Chain, OKC）」
- 引用文献时中英文文献都要覆盖（中文自动化学报/控制与决策 + IEEE/Elsevier）
- 翻译时注意学术用语规范，不要逐词硬翻
- 链接 [[user-current-projects]]（参考已有的 0526-en 翻译风格）
