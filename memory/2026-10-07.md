## Jev Open-Source Alternatives Research

User asked about open-source alternatives to TypeSafe's closed Jev model. Found 4 main projects:

   - GitHub: https://github.com/TheoLeeCJ/SemIf-OpenJev

   - GitHub: https://github.com/nokia-applied-research/AnyJev

4. **von** (⭐869) - Non-autoregressive System One decision model, <15ms latency
   - GitHub: https://github.com/wfzyx/von

**Key finding**: No "pure Jev" exists - TypeSafe hasn't open-sourced Jev. All are community reconstructions.

- LoRA: r=16, alpha=32, target_modules include linear-attention specific layers

- English autumn poem: ✅ Normal output
- Knowledge Q&A (Paris): ✅ Correct
- Math (1+1=2): ✅ Correct

**Web UI deployment**:
- Flask web service created at `/tmp/kev4b_simple_web.py`
- Running on port 8088 (localhost)
- Status: ✅ Running, verified with HTTP 200
- cpolar tunnel: In progress

**Note**: Model outputs include internal thinking/reasoning tags (`<think>...</think>`) which should be cleaned up for production use.

## Lessons Learned

1. **Environment matters**: vllm-env works, finetune-env doesn't for this model
2. **Missing LoRA keys warning is OK**: Model still functions despite missing adapter keys
3. **Port 8080 occupied**: Already in use by another service, used 8088 instead
4. **Model architecture**: Qwen3.5-4B-Base uses custom architecture with linear-attention layers, not standard Qwen

## Lessons Learned
