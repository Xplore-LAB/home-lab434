# Project

> 项目级代码仓库 / 产品原型 / 平台

## 约定
- 代码放在 `src/` 或项目根
- 文档放在 `docs/`
- 脚本放在 `scripts/`
- 测试放在 `tests/`
- 依赖声明：`requirements.txt` / `pyproject.toml` / `package.json`
- 统一用 `README.md` 说明用途、启动方式、依赖

## 模板
```
project/
├── README.md
├── .gitignore
├── src/            # 可选
├── docs/           # 可选
├── scripts/        # 可选
├── tests/          # 可选
└── requirements.txt / pyproject.toml / package.json
```
